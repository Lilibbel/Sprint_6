# Sprint 6
Этот проект содержит автоматизированные тесты для веб-приложения по 
заказу самокатов. Тесты написаны с использованием Python, Selenium 
WebDriver и фреймворка Pytest.

# Инструкция по запуску

1. Установите зависимости:<br> *pip install -r requirements.txt*
2. Запустите тесты (все): <br>*pytest -v*<br>
С генерацией отчёта Allure:<br>
*pytest --alluredir=allure_results* <br>
*allure serve allure_results*

# Требования
1. Python 3.8+
2. Браузер Mozilla Firefox
3. Установленный Geckodriver для Firefox (добавьте его в PATH)
